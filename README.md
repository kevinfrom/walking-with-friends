# Walking With Friends

A simple multiplayer game in Go.

## Development

Run directly without compiling:

```bash
go run ./cmd/server
go run ./cmd/client
```

## Build

Compile the binaries into `bin/`:

```bash
go build -o bin/server ./cmd/server
go build -o bin/client ./cmd/client
```

## Run the binaries

```bash
./bin/server
./bin/client
```
